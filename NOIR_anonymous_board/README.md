# NOIR — анонимная доска

Тёмная glassmorphism-доска для коротких анонимных сообщений. Нет аккаунтов и профилей; у каждого сообщения выбранный срок жизни.

## Запуск локально
Требуется Node.js 18 или новее.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Запустите `npm start` (или `node server.js`).
4. Откройте `http://localhost:3000`.

## Сроки сообщений
1 час, 24 часа, 3 дня или 7 дней. Сервер очищает просроченные сообщения при обращении к API. Хранилище для демо — `data/posts.json`.

## Уже есть
- Адаптивный чёрный стеклянный интерфейс.
- Общая лента через серверный API.
- Автоматическое истечение сообщений.
- Ограничение частоты публикаций: 5 действий в минуту на сетевой адрес.
- Жалобы: сообщение скрывается после 5 уникальных жалоб.
- Лимит 1000 символов, безопасный вывод текста без HTML-вставок.
- Нет регистрации, аватаров или публичных профилей.

## Важно перед открытой публикацией в интернете
Это рабочий стартовый проект, а не готовая к массовому запуску платформа. Для публичного размещения добавьте HTTPS, постоянную базу данных, модераторскую панель и процедуру апелляций, более устойчивое ограничение спама (лучше на уровне reverse proxy/Redis), резервное копирование и правила обработки жалоб. Не доверяйте `X-Forwarded-For`, пока не настроен доверенный прокси. Текущие данные лежат в JSON-файле и рассчитаны на небольшой прототип; на некоторых хостингах файловая система эфемерная.
